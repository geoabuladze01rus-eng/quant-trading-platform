# Roadmap

1. **MVP foundation (current):** mock market data, arbitrage detection, paper-only risk decisions, dashboard and audit trail.
2. **Data quality:** authenticated read-only adapters, normalized order books, persistence, replayable backtests and feed health.
3. **Paper operations:** simulated fills, position accounting, alerts and reconciliation.
4. **Controlled integration:** T-Invest sandbox validation and crypto read-only API validation. Any live-trading proposal requires a separate security review and explicit acceptance process.
